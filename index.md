# About Alaya

**Alaya** is a comprehensive, multi-module Enterprise Resource Planning
(ERP) and business management platform developed for accounting,
operations, marketplace integration, and reporting.

## Overview

Alaya is designed to serve businesses that require an integrated system
covering core financial and operational functions — from accounts
receivable and payable through to inventory, sales, production, and CRM
— while also supporting modern needs such as e-invoicing, marketplace
connectivity, and mobile app access.

## Key Features Summary

| Feature Area | Description |
|----|----|
| Accounting & Finance | AR, AP, General Ledger, GST/SST, e-Invoice |
| Operations | Inventory, Sales, Purchase, Production |
| Customer & Sales | CRM, POS, Promotions, Membership |
| Marketplace | eHub integration (Sitegiant, Member App) |
| Reporting | Reporting tool which support self designing |
| API | REST APIs for mobile apps and third-party integration |
| Customisation | [Module Editor](module_editor.md) for no-code custom module creation |
